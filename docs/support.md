# DosMac support

[Report a problem or request a feature](https://github.com/asaptf/DosMac/issues/new) · [Documentation](../README.md#documentation) · [Privacy policy](privacy.md)

Include your DosMac version, macOS version, Mac architecture, guest release, and clear steps to reproduce the problem. State whether you use the sandboxed edition or a developer build. Describe the expected and actual result.

For installation problems, include the installer stage and disk labels, not the installation media itself. For guest input problems, state whether the footer reports seamless input or captured input. Guest Tools support and current limitations are described in [Guest Tools](guest-tools.md).

Before a destructive guest operation, shut down normally and make a recovery copy. Keep your existing computer when testing different installation media.

GitHub issues are public. Do not upload guest disks, product keys, passwords, private documents, or full logs without reviewing their contents. There is no support account or payment requirement in DosMac.
