Bring your own DOS and classic Windows software to a private retro PC. Keep your library, installation media, guest display and file transfers in one Mac workspace.

## Description

DosMac brings a complete retro PC into a Mac workspace. Create a computer, import your installation images and keep its hard disk, floppy disks and CDs together.

Start with the included PC hardware check. It boots original diagnostic code, accepts keyboard input and displays a color pattern without downloading an operating system or asking for a product key.

For your own software:

• Organize computers and launch them from Library.
• Import local floppy images and CD images.
• Switch installation disks while the computer is running.
• Use the guest display and keyboard inside the app.
• Exchange files through a private shared folder or an exchange floppy.
• Install Guest Tools in supported Windows 98 guests for seamless mouse input and display resolution controls.

Operating systems, commercial applications and their licenses are supplied by you. No DOS, Windows or Microsoft application installation media is included. Compatibility depends on the guest system, media release and software. Guided Windows 95/98 installation remains experimental and may require manual interaction with Setup.

This Mac edition includes its native emulation engine. You do not need to install another emulator or download a native runtime. Your computers and documents stay on your device. DosMac has no project-operated analytics, advertising, subscription or account service.
