Original DosMac test fixtures, dedicated to the public domain under CC0-1.0.
No third-party applications or operating systems are included.
hello.zip / hello.7z: an original DOS batch script inside a wrapper directory.
hello-bcj.7z: the same script with the currently unsupported BCJ compression filter.
traversal.zip: an intentionally unsafe relative path.
symlink.zip: an intentionally unsafe Unix symbolic link entry.
oversize.zip: 129 MiB of compressed zeros to test declared-size rejection before extraction.
media.zip: a 160 KiB zero-filled dummy image for preparation tests; not a formatted or bootable disk.
